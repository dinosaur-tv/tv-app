# Dino TV · Android TV

Открывает домашний экран и показывает его поверх музыки. Основное окно использует `KEEP_SCREEN_ON`; оверлей — также отдельное удержание экрана только пока он виден.

Оверлей освобождает удержание при закрытии и выключении экрана. Без продления оно истекает через 2 минуты. Кнопка питания работает; глобальные тайм-ауты не меняются.

## Сборка

JDK 17, Android SDK 35. Телевизор: Android 8/API 26+.

```bash
./gradlew :app:assembleDebug \
  -PDINO_HOME_URL=https://home.example.com/tv/ \
  -PDINO_API_BASE_URL=https://home.example.com/api
```

Windows: `gradlew.bat`. APK: `app/build/outputs/apk/debug/app-debug.apk`.

Готовая подписанная сборка — в [релизах](https://github.com/dinosaur-tv/tv-app/releases/latest); [как установить](https://github.com/dinosaur-tv/.github/blob/main/docs/INSTALL.md). Workflow `Release APK` собирает её по тегу `vX.Y.Z` из переменных `DINO_HOME_URL`, `DINO_API_BASE_URL` и секретов подписи.

URL должны вести на **ваш** доверенный HTTPS-сервер. Для публикации используйте release-сборку со своим ключом подписи вне Git; debug APK содержит диагностические компоненты.

## Подключение

1. Установите APK и откройте приложение.
2. Введите код с экрана в мини-приложении бота: «Ещё → Код ТВ или телефона». Телевизор привяжется к выбранному дому.
3. Для музыки разрешите доступ к уведомлениям; для оверлея — показ поверх приложений.

Музыку воспроизводит установленный плеер. Поддержка зависит от прошивки ТВ.

Напоминание поверх фильма — карточка в правом верхнем углу: выезжает за 0,46 с, держится 20 секунд с убывающей полоской времени и уходит сама. Кадр она не перехватывает: окно не принимает фокус и касания.

Появление сопровождается мягким двухнотным сигналом (0,98 секунды, восходящая кварта с низкой подложкой и лёгким хорусом), один раз. Звук смешивается с фильмом без запроса аудиофокуса; громкость и mute берутся от ТВ.

Пульт выключен, пока backend не включит `TV_REMOTE_ENABLED=true`. Для обычного экрана не выдавайте `WRITE_SECURE_SETTINGS`.

## Проверки

```bash
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
pre-commit install
pre-commit run --all-files
```

Дополнительно проверьте на ТВ музыку, сон, переподключение и разрешения. Фоновые ограничения Android/прошивки могут влиять на работу. Анимации не гарантируют защиту от выгорания.

Фоновая служба использует `specialUse`, а не ограниченный шестью часами `dataSync` на Android 15. Остановка — из уведомления. Для Google Play потребуется декларация и проверка [типа службы](https://developer.android.com/develop/background-work/services/fgs/service-types#special-use).
