# Dino TV

Домашний экран для Android TV: время, погода и общий календарь в эстетике `quiet modern classic`.

## Что уже реализовано

- нативное Android TV приложение на Kotlin и Jetpack Compose;
- полноэкранный landscape-режим, предотвращающий гашение экрана во время работы;
- экран «Сейчас», детальный день, неделя и месяц;
- управление всеми разделами штатным D-pad пультом;
- карточка «Сейчас играет» для отображения источника, трека и громкости;
- русская локализация даты и демонстрационные данные, чтобы интерфейс можно было увидеть сразу;
- пять переключаемых палитр: лес, камень, табак, taupe и светлый Apple-стиль;
- единый контракт для защищённого сервиса календарей, погоды и Telegram.

Приложение намеренно не содержит ключей Google, погоды или Telegram. Они должны храниться на личном сервере Dino TV, а телевизор получает только короткоживущую сессию и уже подготовленный экранный JSON.

## Запуск

1. Откройте этот каталог в Android Studio.
2. Выберите JDK 17 (в Android Studio он уже встроен).
3. Дождитесь Gradle Sync, затем запустите конфигурацию `app` на Android TV или эмуляторе API 26+.

Для консоли на Windows:

```powershell
$env:JAVA_HOME = 'C:\Program Files\Android\Android Studio\jbr'
.\gradlew.bat :app:assembleDebug
```

## Quality checks

Установите `pre-commit`, затем в папке проекта выполните `pre-commit install`. Перед коммитом запускаются Android Lint и unit-тесты; вручную их можно прогнать так:

```powershell
.\gradlew.bat :app:lintDebug :app:testDebugUnitTest
```

## Архитектура интеграций

Телевизор **не** ходит в Google Calendar и Telegram напрямую. Приватный сервис делает OAuth-подключение каждого человека, хранит refresh token в шифрованном хранилище, агрегирует выбранные календари и отправляет телевизору единый read-only снимок.

Подробный контракт и требования — в [backend/README.md](backend/README.md).

## Музыка

Интерфейс читает стандартную Android `MediaSession` активной Яндекс Музыки на телевизоре: название трека, исполнителя, состояние, паузу/следующий и громкость. После установки нажмите «Подключить Яндекс Музыку» на главном экране и разрешите `Dino TV: музыка` доступ к уведомлениям в системных настройках. Это даёт приложению право получать активную медиасессию, но не читать личные сообщения.

Прямой публичный API Яндекс Музыки для управления чужим аккаунтом, поиском, «Волной» и плейлистами не заявлен, поэтому эти действия нельзя надёжно и безопасно встроить без официальной партнёрской интеграции.

## Ближайшая продуктовая работа

1. Поднять сервис из контракта и сделать пару Google OAuth для двух аккаунтов.
2. Заменить `DemoDashboardRepository` на HTTP-реализацию с авторизацией устройства.
3. Подключить Open-Meteo или другой выбранный источник погоды через сервис.
4. Подключить Telegram webhook и список разрешённых Telegram ID.
5. Добавить ночной режим и незаметный pixel shift против OLED burn-in.
